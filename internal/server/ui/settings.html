Font

A .ttf, .otf or .ttc to draw messages and the menu with. Leave it empty and gumpet looks for one on this machine — Hiragino on macOS, Yu Gothic on Windows.

Turn this off to use gumpet's own bitmap font instead. It is always available, but goes blocky when enlarged.
